# House rules - what is true for every client

One line per rule, dated, in the words it was said in. Read before
writing anything for anyone.

A correction belongs here only when it is about how we work, not about
one business. "Do not promise a reply rate" is a house rule. "Do not
mention our Warsaw office" is that client's. When the same correction
arrives from a second client, move it up here and say so in one line.

- 2026-09-23, owner, sender profiles: "в оптимизации профиля нам нужно раскрыть бизнес целиком. Сиквенсы - это отдельные гипотезы по разным сегментам. Профиль сам по себе никогда не продаст, но он должен отвечать на вопрос «кто это, чем может быть полезен этот человек и что делает его бизнес». Информацию из сиквенсов можно использовать как одно из направлений, но не заострять на нём внимание, особенно в хедлайнах." A profile describes the whole business; the sequence's angle is one bullet, never the headline.
- 2026-09-23, owner, sender profiles: "раздел опыта должен быть унифицирован и полностью одинаковый для всех профилей, даже если их будет 20." The Experience description of the company is one text on every sender profile, real or rented; only the job title changes.
- 2026-09-24, owner, follow-ups: "не надо ему ничего собирать, ты затрахал всем собирать". Offering to build the first set of queries, a list or a map is not a follow-up angle - it became the same closing line in every message. A follow-up carries something already true: a number, an observation about their market, the second product, or one sharp question. Offer to build only when they ask for it.
- 2026-09-24, owner, follow-ups: "мы ж ему настроить помогали, долбоебский вопрос". Read what already happened in the thread before writing the follow-up. Asking whether someone is ready to start a trial you set up together three days ago says plainly that nobody looked.
- 2026-09-24, owner, meetings: "мы просто не записали, теперь будем записывать, так что фолоуап должен мягче быть". Where the outcome of a call was never recorded, the follow-up never advertises that: no asking them to confirm a booking they honoured, no "not sure how it ended". Ask about the next step as though the thread never dropped, and write the outcome into the row the moment a call ends.
