# Upwork as a channel: what an agent may do, and what gets accounts banned

Agencies ask the same thing again and again: several freelancer profiles,
one manager, and the wish to edit profiles daily, answer from one inbox and
bid automatically. This file is what is safe to recommend. It was written
from Upwork's own pages as read on 25.11.2026: the MCP setup page, the API
and MCP terms in force from 06.11.2026, and the support articles on bots and
multiple accounts. Re-check those pages before quoting a limit to a client.
The terms change.

## What exists

- **Upwork has an official MCP server** (since 10.08.2026, free). Each person
  signs in with their own Upwork login through OAuth. API keys are not
  accepted, and an agent hosted on someone else's server cannot sign in.
- **A freelancer's agent can:**
  - search jobs and get matches;
  - draft proposals (they are sent only after the person confirms);
  - read and send messages;
  - work with offers, contracts and milestones;
  - see Connects and earnings;
  - edit availability, employment, languages, education and portfolio.
- **It cannot** edit title, overview, skills, hourly rate or specialized
  profiles: these are not on Upwork's list. An agency account cannot edit
  its members' personal profiles. The API has no write access to those
  fields either.

## Rules that decide the advice

- **One person, one account.** A manager who logs into members' profiles is
  sharing a login, and that is a reason for suspension.
- **No agent picks jobs and sends proposals on its own.** An agent acting
  without a specific human instruction is against the terms, and so is
  ranking jobs by the agent's own criteria and sending. Automatic bidding
  falls under this.
- **No bots, browser automation, job-watching extensions, auto-refresh or
  session tokens in scripts.** Upwork enforces this automatically and makes
  no exceptions.
- **Disclose AI-written text** where the reader would assume a human wrote
  it.

## What to recommend to an agency with several profiles

1. Each member connects their own Upwork to their own agent through the
   official MCP. The manager never logs into a member's account.
2. Every day the agent reads the new jobs in the agency's niche and collects
   the day's keywords. It then writes the edit text for title, overview and
   skills, plus proposal drafts.
3. The member confirms proposals and pastes the profile edits by hand. That
   takes about five minutes a profile a day, until Upwork opens those fields
   to agents.
4. Bidding stays human-confirmed. "Overnight auto-bidding" is exactly what the
   terms forbid. Do not set it up, and say so plainly when asked.

Corrected from: the usual agency setup, where one manager logs into every
member profile from remote machines and runs a third-party auto-bidder. Each
part of that setup is a listed reason for a ban.

## Outreach next to Upwork

A job on Upwork can also be a signal for outreach on LinkedIn to the
client's decision maker. Never write that you saw the job on Upwork. A
complaint about that can get the freelancer's Upwork account blocked. Say
you know they need help with the task, and leave it there.
