# Tools of the plugin's own MCP servers that run without a permission prompt.
#
# One line per tool: "<server> <tool>", the exact name, nothing else on the
# line. allow-read-only.sh lets a call through only on an exact match;
# every other tool keeps the normal prompt. A user's own deny or ask rule
# still wins over this list.
#
# A tool goes in only after its code was read, never because of its name.
# All three must hold:
#   1. the server marks it read-only (readOnlyHint: true);
#   2. its handler only reads - a GET, or a static answer - or it is a
#      price or form check whose server code reserves and creates nothing
#      and costs the user nothing;
#   3. every workspace has it: no admin-only tool, no tool switched on for
#      one team.
# Never here, whatever the server says: anything that spends money or
# credits, sends, enrols, deletes, confirms, starts or stops a collection,
# a search or a scan, or changes a setting. The hook refuses those names on
# its own as well, so a mistake here does not open them.
# When unsure whether a tool spends, it stays out: the cost of leaving a
# read out is one extra prompt, the cost of letting a spend in is money.
#
# Last checked against the servers' code on 2026-10-22. After any change:
#   node hooks/check-allowlist.mjs
# and, with the servers' source at hand, add --source <server>=<dir>.
