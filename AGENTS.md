# Outbound Agent - instructions for Codex

This folder is an outbound sales agent that works through the Grinfi MCP
server. The full instructions live in `CLAUDE.md`; they apply to you word
for word. Read that file first, then the skill for the job at hand in
`.claude/skills/<name>/SKILL.md`, then `business/` for the client's memory.

Codex-specific setup notes are maintained by the Grinfi team in the
article that ships with this kit.
